# Сайт-визитка репетитора корейского языка — Валерия Сон

## О проекте

Taplink-подобный одностраничный сайт для репетитора корейского языка **Валерии Сон**. Страница служит центральной точкой входа для учеников: здесь собраны форматы работы, стиль преподавания и ссылки на все социальные сети.

## Цели

- Предоставить потенциальным ученикам краткое и привлекательное описание репетитора
- Показать форматы занятий и ценовую политику
- Направить пользователей в мессенджеры и соцсети для записи
- Работать идеально на мобильных устройствах (основная аудитория — Instagram/TikTok)

## Структура проекта

```
repetitor/
├── index.html        # Главная страница (единственная страница сайта)
├── style.css         # Стили (mobile-first, корейская эстетика)
├── assets/
│   └── photo.jpg     # Фото репетитора (добавить вручную)
└── README.md         # Документация проекта
```

## Контент страницы

### Блоки сайта (сверху вниз)

1. **Шапка / Hero**
   - Фото Валерии
   - Имя и позиционирование: "Репетитор корейского языка"
   - Короткий слоган

2. **О себе**
   - Стиль преподавания: живой, разговорный, без зубрёжки
   - Опыт и подход: разговорная практика + грамматика под конкретные цели ученика
   - Уровни: с нуля до Upper-Intermediate (A0–B2)

3. **Форматы работы**
   | Формат | Описание |
   |--------|----------|
   | Индивидуальные занятия | 1 на 1 онлайн, гибкое расписание |
   | Разговорный клуб | Мини-группы до 4 человек |
   | Интенсив | Подготовка к TOPIK или поездке |
   | Авторские материалы | PDF, карточки, чек-листы |

4. **Ссылки на соцсети**
   - Telegram (запись на занятия)
   - Instagram (жизнь языка, посты, рилс)
   - TikTok (короткие уроки)
   - YouTube (длинные разборы)
   - VK (для русскоязычной аудитории)

5. **Кнопка CTA**
   - "Записаться на пробный урок" → Telegram

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — flexbox, CSS-переменные, анимации
- **Без фреймворков** — легко редактировать без сборки
- **Mobile-first** — оптимизирован под ширину 320–480px

## Дизайн

- Цветовая палитра: мягкие тёплые тона (персик, кремовый, розово-лиловый) с акцентом на корейскую эстетику
- Шрифты: системные sans-serif + Google Fonts (Noto Sans KR для корейских символов)
- Стиль: минималистичный, "уютный", современный — соответствует аудитории 18–30 лет

## Как запустить

Просто открыть `index.html` в браузере — никаких зависимостей, сборки или сервера не нужно.

## Как задеплоить

Подходит любой статический хостинг:
- **GitHub Pages** — бесплатно, достаточно включить в настройках репозитория
- **Netlify** — drag & drop папки проекта на netlify.com
- **Vercel** — аналогично Netlify
- **Taplink** — как альтернатива, но собственный сайт даёт больше контроля
